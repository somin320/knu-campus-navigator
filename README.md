# KNU Campus Navigator

경북대학교 대구캠퍼스 도보 길찾기 웹 서비스입니다. AI:CRAFT 해커톤 for 27, 팀 MVP의 결과물입니다.

**배포 주소: https://knu-campus-navigator.netlify.app**
설치 없이 PC와 휴대폰 브라우저에서 바로 쓸 수 있습니다.

## 왜 만들었나요

신입생은 건물의 정식 이름, 동번호, 학생들이 부르는 줄임말이 서로 달라서 강의실을 찾는 것부터 헤맵니다. 일반 지도 앱은 캠퍼스 안의 샛길, 계단, 건물 출입구까지는 알려 주지 않습니다. 선배들이 몇 달 동안 걸으며 익힌 길을 신입생이 첫날부터 쓸 수 있도록 만들었습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 건물 검색 | 정식 이름, 동번호, 줄임말(중도, 글플, 공12, 인진관 등)로 검색 |
| 캠퍼스 도보 길찾기 | 팀이 직접 그린 샛길과 출입구까지 반영해, 가장 가까운 출입구로 안내 |
| 계단 회피 | 계단과 경사를 덜 지나는 경로를 버튼 하나로 비교 |
| 연강 이동 확인 | 쉬는 시간과 예상 도보시간을 비교해 여유, 빠듯, 어려움으로 판정 |
| 편의시설 찾기 | 편의점, 학식, 카페, 프린터, 기숙사, 핫플을 가까운 순서로 안내 |
| 내 위치 출발, 경로 공유 | 현재 위치에서 출발하고, 경로를 링크로 공유 |

## 어떻게 동작하나요

1. **보행 데이터**: OpenStreetMap의 보행로에 팀이 직접 확인한 샛길, 계단, 경사, 건물 출입구를 더해 캠퍼스 보행 그래프를 만들었습니다. 지점 2,264개, 길 3,068개, 계단 구간 138개입니다. (`knu-campus-navigator/knu-graph.json`)
2. **길찾기 알고리즘**: 힙 기반 다익스트라로 계산합니다. 출입구가 여러 개인 건물은 모든 출입구를 한꺼번에 출발점과 도착점 후보로 넣고, 건물 안은 통과하지 않습니다. 계단은 1.65배, 경사는 1.10배로 계산하고, 계단 회피를 고르면 계단 25배, 경사 2.5배로 계산합니다. 도보 속도는 분당 67m입니다.
3. **화면**: 네이버 지도 위에 경로를 그립니다. 지도 인증에 실패하면 OpenStreetMap 지도로 자동 전환합니다.
4. **운영 비용**: 서버 없이 정적 웹으로 배포하고, 경로는 브라우저에서 직접 계산하므로 유료 경로 API를 쓰지 않습니다.
5. **검증**: 건물 86곳 사이의 경로 14,620건을 자동으로 계산해 계산과 구조 오류가 없는지 확인했습니다. (`knu-campus-navigator/tools/knu-route-audit.js`)

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `knu-campus-navigator/index.html` | 화면 뼈대 |
| `knu-campus-navigator/src/core.js` | 길찾기 알고리즘, 편의시설 표, 검색 별칭, 연강 판정 |
| `knu-campus-navigator/src/app.js` | 화면 동작, 네이버 지도 연결 |
| `knu-campus-navigator/src/style.css` | 디자인 |
| `knu-campus-navigator/knu-graph.json` | 캠퍼스 보행 데이터 |
| `knu-campus-navigator/tools/knu-map-editor.html` | 보행 데이터를 지도 위에서 고치는 편집기 |
| `knu-campus-navigator/tools/knu-route-audit.js` | 전체 경로 자동 검사 도구 |
| `knu-campus-navigator/tests/` | 자동 테스트 |

## 직접 실행하기

```
cd knu-campus-navigator
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. 네이버 지도는 등록된 주소에서만 뜨고, 그 밖의 주소에서는 OpenStreetMap 지도로 열립니다. 길 데이터를 고치는 방법은 [앱 폴더의 README](knu-campus-navigator/README.md)에 있습니다.

## 생성형 AI 활용

Claude, ChatGPT, OpenAI Codex, Google AI Studio를 기획, 데이터 구축, 코드 작성, 검증, 문서화에 활용했습니다. AI가 만든 결과는 팀이 실제 화면과 현장 지식으로 확인한 뒤 반영했고, 실제로 없는 길을 지우는 판단처럼 현장을 알아야 하는 일은 사람이 직접 했습니다.
